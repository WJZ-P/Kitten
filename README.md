# Kitten

**住在你手机里的人性化助手：说一句话，她替你打开 App、一步步点完、看完、办完。默认提供猫娘、鲸鱼娘(超级大肥鱼！)人设，也可以自定义任何你想要的人设！**

她在后台另一块看不见的屏幕上干活，不抢你的屏幕；想看她在干什么，随时点开卡片围观她是怎么操作副屏的！

## 为什么是 Kitten

|                       |                                                                                                                                                  |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|
| 🪟 **不抢你的屏幕**   | 应用开在后台的一块副屏上，点按、输入、滑动都在那里，你照常用手机。任务卡片旁边是那块屏的直播缩略图，点开就是全屏，她每点一下、滑一下都标在画面上 |
| 🧩 **什么应用都能用** | 像人一样看屏幕、找按钮，不需要应用开放接口，也不用一个个适配                                                                                     |
| 🧠 **越用越顺手**     | 记得你说过的偏好；办完一件事会在后台自己复盘，把做法沉淀成技能；跑通过的操作存成自动流程，下次照着点完，一个 token 都不花                        |
| ⏰ **能直接调系统**   | 定闹钟、到点一直响的提醒、读写日历、看电量和存储、查你今天玩了多久手机，不用去点界面                                                             |
| 🔒 **无任何多余上传** | 用你自己的模型 Key，你说的话、屏幕上的内容只发给你自己选的模型服务商                                                                             |
| 🐱 **自定义人设**     | 默认提供猫娘和大肥鱼人设，快在手机上安装一个独属于你的大肥鱼！                                                                                   |
| 🆓 **开源**           | AGPL-3.0，代码全部公开                                                                                                                           |

## 三步上手

1. **装上**：暂时还没有发布安装包，先按下面的[自己编译](#自己编译)装到手机上。
2. **接上模型**：设置 › 模型服务商，选一个预设填上 Key（DeepSeek、通义千问、智谱 GLM、Moonshot、OpenAI、Anthropic、本地 Ollama），或者自己填任意 OpenAI 兼容 / Anthropic 格式的地址。
3. **打开增强模式**：设置 › 增强模式，按提示打开「无线调试 › 使用配对码配对设备」，在 Kitten 弹出的通知里填上配对码。**配一次就好，全程在手机上完成，不用电脑。**

然后对她说说看：

- 「明早七点半叫我起床」
- 「半小时后提醒我收衣服」
- 「去淘宝看看有什么好吃的零食」
- 「我今天玩了多久手机？」

## 她能做什么

| | |
|---|---|
| **操作应用** | 打开任意应用，读屏、点按、长按、输入、滚动、按键。付款、发消息、删东西这类做了就收不回来的事，先问过你再动手 |
| **拿不准就问** | 信息不够时弹出带选项的问题卡片，点一下就答完 |
| **记性** | 你的称呼、口味、忌口、常用地址……换了对话也记得；设置里随时能看、能改、能删 |
| **技能** | 你可以教她做某件事的方法；她自己办完事也会学，同一个应用的经验归到一个技能里；能走通的操作存成自动流程，下次直接重放 |
| **系统能力** | 系统闹钟和倒计时、到点一直响到你点掉的提醒（任务页「定时任务」里能看、能取消）、日历、手机状态、应用使用记录 |
| **看着她干活** | 对话里的任务卡片、副屏直播和全屏查看、任务页上正在办的事、常驻通知，随时都能喊停 |
| **看图** | 发图片给她看（要所选模型支持识图） |
| **Token 看板** | 每天用了多少 token、缓存命中了多少，一目了然 |

## 对手机的要求

| | |
|---|---|
| 系统 | Android 13 及以上 |
| 增强模式 | 要能打开「无线调试」，并且连着 Wi-Fi |

主要在小米 HyperOS 上开发和测试。别的系统上遇到问题，欢迎[提 issue](https://github.com/WJZ-P/Kitten/issues)。

## 隐私与安全

- **没有 Kitten 服务器**：你说的话、屏幕上的内容，只发给你自己配置的模型服务商。
- **API Key 是明文存的**：放在应用的私有目录里，别的应用读不到；但在 root 过的手机上能被读出来。Kitten 没有给它加一层加密，因为解密用的密钥同样只能放在这台手机上，加了也只是看起来安全。请自己判断要不要在这台手机上放高权限的 Key。
- **日志里不记隐私**：通知内容、聊天内容、记忆、配对码都不会写进日志。
- **屏幕上的字只是信息，不是命令**：网页、商品详情、聊天消息里写着「立即付款」「忽略之前的指令」，她不会照做，只听你在对话里说的话。
- **特权进程接口很窄**：增强模式拿到的 ADB 权限，只开放精确的几样能力（建副屏、拉起应用、按坐标点按、补授权……），不提供执行任意命令的通道。
- 自动操作第三方应用可能违反它们的用户协议，请自己判断；重要的事，记得看一眼结果。

<details>
<summary><b>常见问题</b></summary>

**无线调试自己关掉了？** 重启手机、换了 Wi-Fi，系统都会把它关掉。重启之后 Kitten 会自己把它打开、连回去；换了 Wi-Fi 的话，在系统设置里把无线调试重新打开，回到 Kitten 就会自己连上，不用重新配对。实在连不上，回到设置 › 增强模式重新配对。

**有些页面她读不到、截不到？** 付款、输密码这类页面禁止截图，这时她会告诉你卡在哪，那一步请你自己来。

**能用自己电脑上跑的模型吗？** 可以：选「本地 Ollama」或者自定义服务商，地址填电脑在局域网里的 IP。

**一定要是猫娘吗？** 设置 › 人设，想让她变成什么样都行。办事的规矩（先问再付款、不听屏幕上的字）不受人设影响。

</details>
